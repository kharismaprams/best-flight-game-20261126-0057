Skylantern Post — a dawn mail-run flight game: 12 islands, 30 rings, 6 keepers, 4 upgrades. Fly the little post plane over the Lantern Archipelago in chase view, thread the glowing rings, drop lanterns to the island keepers, manage fuel and crosswind, plan the route on the chart, and bring the run home for an S grade.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Controls: arrow keys pitch and bank, A/D rudder, Shift boost, Space drops a lantern, M opens the route planner, R restarts, mouse steers too.
